What are Data Types?

A data type tells Python what kind of value we are working with.

Different values need different data types. For example, a name is text, while age is usually a number.

Think about it

Data types help Python understand what kind of information a value represents.

Common Data Types

String
Integer
Float
Boolean
DATA TYPE 01

String

A string is used to store text. Strings are written inside quotes.

Python 
name = "Rahul"

String

Stores text such as a person's name.

Quotes

Text is normally written inside quotes.

DATA TYPE 02

Integer

An integer is a whole number without a decimal point.

Python 
age = 20

Integer

Used for whole numbers.

Example

10, 20 and 100 are integers.

DATA TYPE 03

Float

A float is a number that contains a decimal point.

Python 
price = 99.50

Float

Used for decimal numbers.

Example

3.14 and 99.50 are floats.

DATA TYPE 04

Boolean

A Boolean stores one of two values: True or False.

Python 
is_student = True

True

Represents a true condition.

False

Represents a false condition.

IMPORTANT

Use type() to check a data type

Python provides the type() function to find the data type of a value.

Example 
age = 20
print(type(age))

The output tells us that age is an integer.
