LET'S BEGIN

Why Do We Need Error Handling?

Sometimes a Python program encounters a problem while it is running.

For example, a user might enter text when the program expects a number.

Problem 
age = int(input("Enter your age: "))

If the user enters hello, Python will produce an error.

Good programs expect problems.

Error handling allows us to respond to errors instead of allowing the program to stop unexpectedly.

Error Handling Helps You

Prevent unexpected crashes
Show useful messages
Handle invalid input
Build reliable programs
CORE CONCEPT

try and except

Python provides try and except to handle errors.

Python 
try:
    number = int(input("Enter a number: "))
    print(number)

except:
    print("Please enter a valid number.")

try

Contains code that might cause an error.

except

Runs when an error occurs.

Message

Gives the user useful information.

Safe

The program can continue safely.

NEXT STEP

The finally Block

The finally block runs whether an error happens or not.

Example 
try:
    print("Hello")

except:
    print("Something went wrong")

finally:
    print("Program finished")
Remember

try → attempt the code
except → handle the error
finally → always runs

WORKING WITH DATA

File Handling

Python can create, read and write files.

This allows programs to store information even after the program is closed.

Think of a file like storage.

Your program can put information into the file and retrieve it later.

Common File Operations

Read
Write
Append
FIRST STEP

Opening a File

Python uses the open() function to work with files.

Python 
file = open("student.txt", "r")

content = file.read()

print(content)

file.close()

File Name

student.txt

Mode

r means read.

Read

Get the file content.

Close

Close the file when finished.

CREATE & SAVE

Writing to a File

The w mode allows us to write data into a file.

Python 
file = open("student.txt", "w")

file.write("Welcome to StudySense AI!")

file.close()
Be careful with "w"

Write mode can replace the existing contents of a file.

ADD MORE DATA

Appending to a File

The a mode adds new content without removing the existing content.

Python 
file = open("student.txt", "a")

file.write("\nPython is fun!")

file.close()
BETTER WAY

Using with open()

Python also provides a cleaner way to work with files using with.

Python 
with open("student.txt", "r") as file:
    content = file.read()
    print(content)
Why use it?

Python automatically handles closing the file after the block finishes.
