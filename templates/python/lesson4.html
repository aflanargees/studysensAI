LET'S BEGIN

What are Operators?

Operators are special symbols that tell Python to perform an operation on values.

We can use operators to calculate numbers, compare values and combine conditions.

Think about it

Operators are like buttons on a calculator. They tell Python what operation to perform.

Common Operators

Arithmetic
Comparison
Logical
Assignment
OPERATOR TYPE 01

Arithmetic Operators

Arithmetic operators are used to perform mathematical calculations.

Python 
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)

+

Addition

-

Subtraction

*

Multiplication

/

MORE OPERATORS

Other Arithmetic Operators

Python also provides operators for remainder and powers.

Example 
print(10 % 3)
print(2 ** 3)

% gives the remainder, while ** is used for powers.

OPERATOR TYPE 02

Comparison Operators

Comparison operators compare two values. The result is usually True or False.

Python 
age = 20

print(age > 18)

==

Equal to

!=

Not equal to

>

Greater than

<

Less than

OPERATOR TYPE 03

Logical Operators

Logical operators are used to combine conditions.

Python 
age = 20

print(age > 18 and age < 30)

and

Both conditions must be True.

or

At least one condition must be True.

not

Reverses a Boolean result.

IMPORTANT

Assignment Operator

The = operator assigns a value to a variable.

Example 
score = 100

Here, the value 100 is assigned to the variable score.
