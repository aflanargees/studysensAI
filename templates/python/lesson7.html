What is a Function?

A function is a reusable block of code that performs a specific task.

Instead of writing the same code again and again, we can place it inside a function and call it whenever we need it.

Think about it

A function is like a small machine. You give it some input, it performs a task, and it can give you an output.

Functions Can

Reuse code
Reduce repetition
Organize programs
Return results
BASIC EXAMPLE

Creating a Function

Python 
def greet():
    print("Hello!")

greet()

def

Used to create a function.

greet()

The name of our function.

print()

The code performed by the function.

Calling

Writing greet() runs the function.

IMPORTANT CONCEPT

Function Parameters

Parameters allow us to pass information into a function.

Example 
def greet(name):
    print("Hello", name)

greet("Afa")
USEFUL CONCEPT

Returning a Value

The return keyword sends a result back from the function.

Example 
def add(a, b):
    return a + b

result = add(10, 20)

print(result)

The result of this program is 30.
