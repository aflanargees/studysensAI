What is a Variable?

A variable is a name that is used to store information in a Python program.

Think of a variable as a labelled box. We can put a value inside the box and use it later.

Think about it

A variable gives a name to a piece of information so that we can use it easily later.

Variables Can Store

Names
Numbers
Text
Other values
BASIC EXAMPLE

Creating a Variable

Python 
name = "Rahul"
age = 20

name

Stores the text Rahul.

age

Stores the number 20.

=

Assigns a value to a variable.

Value

The information being stored.

IMPORTANT RULE

Variable names are case-sensitive

In Python, name and Name are treated as different variable names.

Example 
name = "Daisy"
Name = "Rahul"
