YOUR FINAL PROJECT

Student Grade Manager

Welcome to your final Python lesson! You have learned the building blocks of Python. Now it is time to combine them into one useful program.

You will build a simple Student Grade Manager that stores student information, calculates grades and displays results.

Your goal

Build a program that can take student marks, calculate the average and determine the student's grade.

What You Will Use

Variables
Conditions
Loops
Lists & Dictionaries
Functions
PROJECT FLOW

How the Program Works

1. Student

Ask the user for the student's name.

2. Marks

Get marks for different subjects.

3. Average

Calculate the average mark.

4. Grade

Display the final grade.

PROJECT RULE

Grade System

Your program can use the following grading system:

90 – 100 → A+
80 – 89 → A
70 – 79 → B
60 – 69 → C
50 – 59 → D
Below 50 → F
Think before coding!

Try to decide which Python concepts you need before writing the program.

02
BUILD IT STEP BY STEP

Build the Project

STEP 1

Get Student Information

First, ask the user for the student's name.

Python 
name = input("Enter student name: ")

print("Student:", name)
STEP 2

Store Marks

We can use a list to store marks.

Python 
marks = [85, 76, 92, 68, 88]
STEP 3

Calculate the Average

Python's built-in sum() and len() functions make this easy.

Python 
average = sum(marks) / len(marks)

print("Average:", average)
STEP 4

Calculate the Grade

Use conditional statements to determine the student's grade.

Python 
if average >= 90:
    grade = "A+"

elif average >= 80:
    grade = "A"

elif average >= 70:
    grade = "B"

elif average >= 60:
    grade = "C"

elif average >= 50:
    grade = "D"

else:
    grade = "F"

print("Grade:", grade)
PUT IT TOGETHER

Complete Example

Python 
name = input("Enter student name: ")

marks = [85, 76, 92, 68, 88]

average = sum(marks) / len(marks)

if average >= 90:
    grade = "A+"
elif average >= 80:
    grade = "A"
elif average >= 70:
    grade = "B"
elif average >= 60:
    grade = "C"
elif average >= 50:
    grade = "D"
else:
    grade = "F"

print("\nStudent:", name)
print("Average:", average)
print("Grade:", grade)
