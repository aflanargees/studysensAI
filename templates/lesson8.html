Lists & Dictionaries

Learn how Python stores multiple values.

What is a List?

A list is used to store multiple values in a single variable. Lists are written using square brackets [ ]. 

fruits = ["apple", "banana", "orange"]

print(fruits)
Remember: Lists can store multiple items and the items can be changed.

List Example

colors = ["red", "blue", "green"]

Accessing List Items

List items are accessed using their index number. Python starts counting from 0. 

fruits = ["apple", "banana", "orange"]

print(fruits[0])
print(fruits[1])
The first item has index 0, the second item has index 1.

Changing List Items

List items can be changed by assigning a new value to an index. 

fruits = ["apple", "banana", "orange"]

fruits[1] = "mango"

print(fruits)

What is a Dictionary?

A dictionary stores data as key-value pairs. Dictionaries use curly brackets { }. 

student = {
    "name": "Rahul",
    "age": 20,
    "city": "Kochi"
}

print(student["name"])

Key + Value

name is the key and Rahul is its value.

Accessing Dictionary Values

Dictionary values can be accessed using their keys. 

student = {
    "name": "Rahul",
    "age": 20
}

print(student["name"])
print(student["age"])
