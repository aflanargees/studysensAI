What is a Loop?

A loop is used to repeat a block of code multiple times.

Instead of writing the same code again and again, we can use a loop to perform the task automatically.

Think about it

If you want to print "Hello" five times, you don't need to write print() five times. A loop can do it for you.

Loops Can

Repeat code
Save time
Process data
Automate tasks
BASIC EXAMPLE

The for Loop

Python 
for i in range(5):
    print("Hello")

for

Starts a for loop.

range(5)

Repeats the loop 5 times.

print()

The code that gets repeated.

Repeat

The code runs again and again.

IMPORTANT CONCEPT

The while Loop

A while loop keeps running as long as its condition is True.

Example 
count = 1

while count <= 3:
    print(count)
    count = count + 1
USEFUL FUNCTION

Using range()

The range() function generates a sequence of numbers that can be used with loops.

Example 
for i in range(1, 6):
    print(i)

This prints the numbers from 1 to 5.
