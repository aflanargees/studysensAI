LET'S BEGIN

What is a Function?

A function is a reusable block of code that performs a particular task.

Instead of writing the same code again and again, we can place it inside a function and call it whenever we need it.

Simple idea

Write once → reuse many times.

Why Use Functions?

Reuse code
Reduce repetition
Organize programs
Make code easier to maintain
FIRST STEP

Creating a Function

Python uses the def keyword to create a function.

Python 
def greet():
    print("Hello!")

greet()

def

Starts a function definition.

greet

The name of the function.

Body

Contains the code to execute.

Call

greet() runs the function.

IMPORTANT CONCEPT

Parameters and Arguments

A function can receive information through parameters. The actual value passed to the function is called an argument.

Example 
def greet(name):
    print("Hello", name)

greet("Afa")
Remember

name is the parameter.
"Afa" is the argument.

LEVEL UP

Multiple Parameters

A function can accept more than one parameter.

Python 
def add(a, b):
    print(a + b)

add(10, 20)

Here, a receives 10 and b receives 20.

IMPORTANT

Returning a Value

The return statement sends a value back from a function.

Python 
def add(a, b):
    return a + b

result = add(10, 20)

print(result)

Input

Values enter the function.

Process

The function performs a task.

Return

A result is sent back.

Output

The result can be displayed or used.

USEFUL FEATURE

Default Parameters

A parameter can have a default value. That value is used when no argument is provided.

Example 
def greet(name="Student"):
    print("Hello", name)

greet()
greet("Afa")

The first call uses Student as the default value.

THINK LIKE A PROGRAMMER

How a Function Works

Define

Create the function.

Call

Run the function.

Process

The function executes its code.

Return

The result comes back.
