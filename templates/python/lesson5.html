What are Conditional Statements?

Conditional statements allow a Python program to make decisions based on a condition.

Python checks whether a condition is True or False and then executes the appropriate code.

Think about it

If it is raining, you take an umbrella. Otherwise, you don't.

Conditional Keywords

if
elif
else
Conditions
BASIC EXAMPLE

Using an if Statement

Python 
age = 20

if age >= 18:
    print("You are an adult")

age

Stores the number 20.

age >= 18

Checks whether age is at least 18.

if

Checks the condition.

print()

Displays the result.

IMPORTANT CONCEPT

if...else

Use else when you want Python to execute another block when the condition is False.

Example 
age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")
MULTIPLE CONDITIONS

if...elif...else

Use elif when you need to check more than one condition.

Example 
marks = 75

if marks >= 90:
    print("Excellent")
elif marks >= 50:
    print("Pass")
else:
    print("Fail")
