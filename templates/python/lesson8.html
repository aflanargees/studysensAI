LET'S BEGIN

What are Lists & Dictionaries?

Lists and dictionaries are used to store multiple pieces of data inside a single variable.

A list stores items in an ordered collection, while a dictionary stores data using key-value pairs.

Think about it

A list is like a shopping list where items are stored one after another. A dictionary is like a real dictionary where each word has a corresponding meaning.

They Can

Store multiple values
Organize data
Be modified
Make programs easier
BASIC EXAMPLE

Python Lists

Python 
fruits = ["apple", "banana", "orange"]

print(fruits)

Ordered

Items keep their position.

Multiple

A list can contain many values.

Changeable

List items can be modified.

Index

Items can be accessed using indexes.

IMPORTANT CONCEPT

Accessing List Items

Python uses indexes to access individual items in a list. The first item starts at index 0.

Example 
fruits = ["apple", "banana", "orange"]

print(fruits[0])
print(fruits[1])

Output: apple and banana.

USEFUL CONCEPT

Adding Items to a List

The append() method adds a new item to the end of a list.

Example 
fruits = ["apple", "banana"]

fruits.append("orange")

print(fruits)

Output: ["apple", "banana", "orange"]

ANOTHER DATA STRUCTURE

Python Dictionaries

Python 
student = {
    "name": "rahul",
    "age": 21,
    "course": "CSE"
}

print(student["name"])

Key

Identifies the stored value.

Value

The actual information stored.

Organized

Data is stored using key-value pairs.

Easy Access

Values can be accessed using keys.

REMEMBER

Accessing Dictionary Values

Instead of using an index, dictionaries use keys to access their values.

Example 
student = {
    "name": "rahul",
    "age": 21
}

print(student["name"])
print(student["age"])

Output: rahul and 21.
