COLLECTION TYPE

Python Tuples

A tuple is a collection of values that is ordered and unchangeable.

Python 
colors = ("red", "blue", "green")

print(colors)

Ordered

Items keep their position.

Unchangeable

Items cannot be modified.

Indexed

Items can be accessed using indexes.

Parentheses

Tuples normally use ( ).

IMPORTANT CONCEPT

Accessing Tuple Items

Just like lists, tuples use indexes. Remember that indexing starts from 0.

Example 
colors = ("red", "blue", "green")

print(colors[0])
print(colors[2])

Output: red and green.

IMPORTANT

Why Can't We Change a Tuple?

Tuples are immutable. That means their values cannot be changed after the tuple is created.

Example 
colors = ("red", "blue", "green")

# This will cause an error

colors[0] = "yellow"
Simple way to remember

List = can change
Tuple = cannot change

COLLECTION TYPE

Python Sets

A set is a collection that stores unique values. Duplicate values are automatically removed.

Python 
numbers = {1, 2, 3, 3, 4, 4}

print(numbers)

Unique

Duplicate values are removed.

Unordered

Items don't have fixed positions.

Add

New values can be added.

Remove

Values can be removed.

USEFUL METHODS

Adding and Removing Set Items

Use add() to add a value and remove() to remove a value.

Example 
numbers = {1, 2, 3}

numbers.add(4)

numbers.remove(2)

print(numbers)
REMEMBER THIS

List vs Tuple vs Set

List

Ordered
Changeable
Allows duplicates

Tuple

Ordered
Unchangeable
Allows duplicates

Set

Unordered
Changeable
No duplicates

Dictionary

Key → Value
Changeable
Keys are unique
